PROGRESO DEL ENTORNO 0% COMPLETADO

Completa los pasos para tener tu streamer listo para emitir.

1. Python 3.10+ & Git REQUISITO BASE

Instala Python 3.10 o superior (marcando "Add Python to PATH") y descarga el repositorio oficial.

Comando de terminal:
pip install -r requirements.txt
2. OBS Studio / PRISM Live VIDEO 9:16 VERTICAL

Configura el lienzo a 1080x1920 para TikTok Live y añade una fuente de navegador (Browser Source) conectada al overlay web.

Ajuste recomendado: 1080 x 1920 (60 FPS)
• Habilita OBS WebSocket Server en el puerto 4455 para cambio de escenas inteligente por IA.
3. VB-Audio Virtual Cable AUDIO & LIP-SYNC

Instala el driver gratuito de cable virtual para canalizar la voz sintetizada de la IA sin capturar ruidos externos.

Enrutamiento de audio: Descargar Driver ↗
• Salida TTS de la IA ➔ CABLE Input
• Entrada Mic en OBS y VSeeFace ➔ CABLE Output
4. VSeeFace / Avatar 3D (.VRM) SINCRONIZACIÓN 3D

Carga tu modelo 3D y activa la sincronización labial (Lip-sync) por micrófono escuchando el cable virtual.

Modo sin webcam: Lip-Sync por Audio
• El avatar moverá la boca y parpadeará solo cuando la IA hable, sin necesidad de cámara web física.
5. Claves de API & Archivo .env CEREBRO & VOZ

Obtén tu API Key gratuita de Gemini (Google AI Studio) y ElevenLabs para activar la inteligencia y la voz natural.

Estructura de credenciales: Generar en Studio ↗
GEMINI_API_KEY=AIzaSy...
ELEVENLABS_API_KEY=sk_...
6. Lanzamiento & Prueba en Vivo EN VIVO

Inicia el motor con un solo comando y realiza una prueba enviando un regalo simulado o mensaje en el chat.

Comando de ejecución:
python -m leviatan.main
